<h1 id="노트북-lm-기반-c-side-공부">노트북 LM 기반 C-SIDE 공부</h1>
<h1 id="요약">1 요약</h1>
<p>제시된 소스들을 바탕으로 <strong>C-SIDE(Cell type-Specific Inference of Differential Expression)</strong> 논문의 핵심 내용을 요약해 드립니다.</p>
<h3 id="c-side의-개요-및-목적">1. C-SIDE의 개요 및 목적</h3>
<p><strong>C-SIDE</strong>는 공간 전사체(Spatial Transcriptomics) 데이터에서 <strong>특정 세포 유형 내에서의 차등 발현(Differential Expression, DE)</strong> 유전자를 탐지하기 위해 개발된 일반 모수적 통계 방법입니다. 이 기술의 핵심 목적은 공간적 위치, 병리적 특징과의 인접성, 또는 세포 간 상호작용과 같은 다양한 **조직 맥락(Tissue Context)**에 따라 세포의 유전자 발현이 어떻게 변화하는지 정확하게 추정하는 것입니다.</p>
<h3 id="주요-해결-과제-세포-혼합cell-type-mixtures-문제">2. 주요 해결 과제: 세포 혼합(Cell Type Mixtures) 문제</h3>
<p>기존의 공간 전사체 분석법들이 직면한 가장 큰 문제는 하나의 측정 단위(픽셀 또는 스팟) 내에 <strong>여러 세포 유형이 섞여 있을 수 있다는 점</strong>입니다.</p>
<ul>
<li><strong>편향 발생:</strong> 세포 유형의 비율 변화를 고려하지 않고 DE를 분석하면, 실제 발현 변화가 아닌 세포 구성의 차이로 인해 잘못된 결과(편향)가 도출될 수 있습니다.</li>
<li><strong>C-SIDE의 해결책:</strong> C-SIDE는 각 픽셀의 세포 유형 비율을 먼저 추정한 후, 이를 모델에 반영하여 특정 세포 유형에서 발생하는 고유한 발현 변화만을 분리해 냅니다.</li>
</ul>
<h3 id="분석-알고리즘-및-작동-원리">3. 분석 알고리즘 및 작동 원리</h3>
<p>C-SIDE의 분석 과정은 크게 세 단계로 나뉩니다:</p>
<ol>
<li><strong>세포 유형 비율 추정:</strong> 단일 세포 RNA-seq(scRNA-seq) 참조 데이터를 활용해 각 픽셀에 포함된 세포 유형별 비율을 계산합니다.</li>
<li><strong>모수적 모델 피팅:</strong> 정의된 공변량(Covariates, 예: 거리, 지역 등)을 사용하여 유전자 발현을 모델링합니다. 이때 로그 선형(Log-linear) 모델을 사용하여 세포 유형별 DE 추정치와 표준 오차를 구합니다.</li>
<li><strong>통계적 추론:</strong> 샘플 간의 기술적/생물학적 변이를 고려하여 여러 반복 실험(Replicates) 데이터를 통합하고, 최종적으로 통계적으로 유의미한 유전자를 식별합니다.</li>
</ol>
<h3 id="다양한-활용-시나리오">4. 다양한 활용 시나리오</h3>
<p>C-SIDE는 매우 유연한 프레임워크를 가지고 있어 다음과 같은 다양한 연구에 적용될 수 있습니다:</p>
<ul>
<li><strong>해부학적 지역 간 비교:</strong> 조직 내 서로 다른 영역(예: 소뇌의 전엽 vs 결절) 사이의 발현 차이 분석.</li>
<li><strong>거리 기반 분석:</strong> 특정 지표(예: 시상하부 중앙선)로부터의 거리에 따른 변화 분석.</li>
<li><strong>병리적 특징과의 관계:</strong> 알츠하이머병의 <strong>아밀로이드 베타 플라크(Aβ plaque)</strong> 밀도에 따른 면역 세포의 반응 분석.</li>
<li><strong>세포 간 상호작용:</strong> 특정 세포 유형이 인접해 있을 때 발생하는 발현 변화 분석.</li>
<li><strong>비모수적 분석:</strong> 구체적인 가설 없이도 조직 전체의 일반적인 공간 발현 패턴을 탐색 가능.</li>
</ul>
<h3 id="소프트웨어-구현">5. 소프트웨어 구현</h3>
<p>이 알고리즘은 R 패키지인 **<code>spacexr</code>**에 포함되어 배포되고 있으며, 공간 RNA 데이터 처리를 위한 <code>SpatialRNA</code> 객체와 참조 데이터를 위한 <code>Reference</code> 객체 등을 사용하여 분석을 수행합니다.</p>
<p>요약하자면, C-SIDE는 공간 전사체 데이터에서 <strong>세포 혼합의 한계를 극복</strong>하고, <strong>다양한 생물학적 요인에 따른 세포 유형별 발현 변화를 정밀하게 분석</strong>할 수 있게 해주는 혁신적인 도구입니다.</p>
<p>더 구체적으로 알고 싶은 부분(예: 수학적 모델링, 특정 실험 결과 등)이 있다면 말씀해 주세요!</p>

<h4 id="slide-1-공간-전사체-분석의-핵심-과제와-c-side의-목적"><strong>Slide 1: 공간 전사체 분석의 핵심 과제와 C-SIDE의 목적</strong></h4>
<ul>
<li><strong>핵심 문제 (Motivation):</strong> 공간 전사체(ST) 데이터의 픽셀(Pixel)은 여러 세포 유형이 섞여 있는 **세포 혼합물(Cell type mixtures)**인 경우가 많습니다.</li>
<li><strong>문제점:</strong> 세포 구성 비율의 변화를 고려하지 않으면, 실제 유전자 발현 변화가 아닌 세포 비율의 차이를 발현 변화로 오인하는 편향(Bias)이 발생합니다.</li>
<li><strong>C-SIDE의 해결책:</strong> 각 픽셀의 세포 유형 비율을 모델에 통합하여, **특정 세포 유형 내에서의 차등 발현(Cell type-specific DE)**을 통계적으로 추정합니다.</li>
</ul>

<li>표준 오차(Standard Error) <span class="katex--inline"><span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mi>s</mi></mrow><annotation encoding="application/x-tex">s</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height: 0.43056em; vertical-align: 0em;"></span><span class="mord mathnormal">s</span></span></span></span></span>를 계산하고, <strong>Z-test</strong>를 통해 유의 확률(<span class="katex--inline"><span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mi>P</mi></mrow><annotation encoding="application/x-tex">P</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height: 0.68333em; vertical-align: 0em;"></span><span class="mord mathnormal" style="margin-right: 0.13889em;">P</span></span></span></span></span>-value)을 도출합니다.</li>
<li>Benjamini-Hochberg 절차를 사용하여 다중 가설 검정(FDR)을 수행합니다.</li>

</li>

<h2 id="c-side-공간-전사체-데이터를-위한-세포-유형별-차등-발현-분석-모델">C-SIDE: 공간 전사체 데이터를 위한 세포 유형별 차등 발현 분석 모델</h2>
<h2 id="개요-및-목적">1. 개요 및 목적</h2>
<p>C-SIDE는 공간 전사체(Spatial Transcriptomics) 데이터에서 하나의 픽셀(Pixel) 내에 여러 세포 유형이 섞여 있는 <strong>세포 혼합(Cell type mixtures)</strong> 문제를 해결하기 위해 설계되었습니다. 이 모델의 목적은 특정 세포 유형 내에서 공간적 위치나 병리적 특성(예: 아밀로이드 플라크 밀도)과 같은 **공변량(Covariates)**에 따른 유전자 발현 변화를 통계적으로 정확하게 추정하는 것입니다.</p>
<h2 id="계층적-확률-모델-hierarchical-probabilistic-model">2. 계층적 확률 모델 (Hierarchical Probabilistic Model)</h2>
<p>C-SIDE는 관측된 RNA 카운트 데이터를 모델링하기 위해 포아송 분포와 로그 선형 모델을 결합한 계층적 구조를 사용합니다.</p>

<h3 id="신뢰-영역-최적화-trust-region-optimization">4.2 신뢰 영역 최적화 (Trust-region Optimization)</h3>
<p>우도 함수(Likelihood function)를 최적화하기 위해 C-SIDE는 <strong>2차 신뢰 영역 기반 최적화</strong> 알고리즘을 사용합니다. 이 방식은 로그 우도의 2차 테일러 근사(Quadratic Taylor approximation)를 반복적으로 풀면서 매 단계마다 매개변수의 변화량을 적응적으로 제한하여 안정적인 수렴을 보장합니다.</p>

<h1 id="계층적-확률-모델">4 계층적 확률 모델</h1>
<p>레퍼런스 18(RCTD 논문)과 62(DerSimonian-Laird 메타 분석)가 추가됨에 따라, C-SIDE의 **계층적 확률 모델(Hierarchical Probabilistic Model)**을 가장 낮은 데이터 관측 단계부터 가장 높은 인구 집단 추론 단계까지 통합적으로 설명할 수 있게 되었습니다.</p>

<h3 id="요약-1">요약</h3>
<p>이 계층적 모델을 통해 C-SIDE는 **“포아송 샘플링(1단계) → 세포 혼합 해소(2단계, Ref 18) → 세포별 발현 변화 추정(3단계) → 샘플 간 통합(4단계, Ref 62)”**의 과정을 거쳐, 복잡한 조직 환경 속에서 특정 세포 유형이 어떻게 반응하는지를 정밀하게 계산해 낼 수 있습니다.</p>

<p>이 두 문단은 C-SIDE가 <strong>(1) 공변량을 통해 세포의 환경을 정의하고, (2) 각 세포 유형의 고유한 반응(<span class="katex--inline"><span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mi>α</mi></mrow><annotation encoding="application/x-tex">\alpha</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height: 0.43056em; vertical-align: 0em;"></span><span class="mord mathnormal" style="margin-right: 0.0037em;">α</span></span></span></span></span>)을 개별적으로 추정하며, (3) 유전자별 노이즈를 정밀하게 제어</strong>하여 기존 GLM 방식보다 훨씬 정교하게 공간적 발현 변화를 분석할 수 있음을 이론적으로 설명하고 있습니다.</p>
